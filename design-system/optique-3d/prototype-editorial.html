Build note — where this departs from the reference

The layout, type treatment and panel rhythm follow the reference exactly. Two colours do not: measured against this warm ground, the reference’s brass nav accent reads about 2.83:1 and its grey caption copy about 2.53:1 — both below the 4.5:1 minimum, and the caption copy is the hardest text on the page to read. Deepening each by a few steps holds the look and clears the bar.

#A89A54 reference brass — 2.83:1 fail
#6F6730 used here — 5.13:1 pass
#9A9A96 reference caption — 2.53:1 fail
#6E6E6A used here — 4.58:1 pass
